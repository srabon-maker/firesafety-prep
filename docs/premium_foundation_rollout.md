# Fire Safety BD freemium: foundation and pilot
This phase is NOT a commercial release. It adds account-specific expiring promotional access, an admin grant/revoke audit trail, proposed plan prices, item-level interview paywall and a read-only membership screen. No purchase, revenue, coupon, subscription renewal, AdMob SDK or ad delivery yet. All current content is free by default (empty marking table); all ad flags are off. Job news, emergency safety tips, community, marketplace, notes, question bank and tests remain unchanged. Admin can mark selected interview records Premium. Legacy clients see free items only, preview clients receive locked titles/metadata but neither Bangla nor English answer; body search cannot reveal matches on locked answers. Valid registered bearer + unexpired UTC membership unlocks answers. Previously downloaded/viewed answers cannot be revoked from copies.
 
## Rollout
1. Back up DB; verify dynamic homepage schema and BIGINT unsigned users.id/homepage_content.id. Apply backend/migrations/20261125_premium_foundation.sql.
2. Deploy reviewed main commit via cPanel (helper before homepage API). Do not activate paywall for existing content until app update is available.
3. Smoke test new admin pages authenticated and logged out, CSRF rejection, expired and revoked entitlement, one disposable user grant/revoke, and Free/Premium marking. Verify logged-out legacy GET excludes marked items; preview GET returns both titles but blank body/body_en; search for a unique locked answer term must not return marked row. Active user gets answers; expired, invalid and another user's tokens do not. Draft records remain unavailable. Revert test marks/grants after test.
4. Build using original Android signing identity; bump Play version code at actual release only. Test status page and locked interview UI on device.
5. Ads page stores requested future placements and a 0–2 daily full-screen cap. Server explicitly reports ads_active=false and purchase_available=false. Changing settings cannot cause SDK ads or money collection.
