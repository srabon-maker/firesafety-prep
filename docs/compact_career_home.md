# Compact career home
Home displays three small links below Marketplace by default. Job Alert stays in Jobs; Profile no longer repeats the hub. The existing homepage settings field supports career ordering and visibility. Legacy configurations default to visible; saving an order without career stores an internal career_off marker, omitted from the admin field and API. No SQL migration is required. Older Flutter builds ignore the new key. New builds also support older API responses.
