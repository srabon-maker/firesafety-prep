# Admin post deletion
The integrated dashboard and separate review page offer a single-post permanent delete action with confirmation. No existing post is deleted during deployment. Login and CSRF checks precede the action. Existing hide/restore and moderation remain unchanged. The helper verifies live InnoDB tables and CASCADE foreign keys from comments, likes and reports to posts, and locks the selected post before deletion. No new schema migration if the existing community migration is applied. Related records are removed by cascade. After commit, uniquely referenced local images with the expected generated filename are removed best-effort; shared images remain; failures are reported. Backups and cached copies are not removed. Test on a disposable post with a comment, like and report: cancel prompt, unauthorized/CSRF attempts, delete, verify feed and dependent records disappear, unrelated records remain, image URL no longer serves the file, repeated deletion fails gracefully. Test hidden/pending/rejected posts too. No real production post deletion performed.
